# Hainur Fadillah Portfolio

Interactive Solar Eclipse, 3D Constellation Globe & Zero-Gravity Asteroid Portfolio built with React, TypeScript, Vite, WebGL, HTML5 Canvas, and Anime.js.

## Highlights
- **Cinematic Scroll Choreography**: Name-only opening transitions into the arriving volcanic Eclipse Planet, an interactive 360° draggable WebGL 3D planet with real astronomical constellations (**Cassiopeia** for the 5 works plus **Crux**, **Orion**, **Ursa Major**, **Scorpius**, **Cygnus**, and **Lyra**), and a meteor-burst handoff into a zero-gravity floating asteroid field.
- **Interactive Zero-Gravity Works & Contributions**:
  1. [TelyuCan](https://telyucan.app/) (Full-Stack Web Dev & Project Manager, live demo walkthrough + 4 sample pages)
  2. [Telyuji](https://telyuji-02704c185fa1.herokuapp.com/) (Full-Stack Web Dev & Project Manager, live demo walkthrough + 4 sample pages)
  3. [Credit Card Fraud Monitoring Dashboard](https://public.tableau.com/app/profile/hainur.fadillah/viz/CreditCardFraudDashboard_Hainur/CreditCardFraudDashboard?publish=yes) (Data Analytics, Tableau Public)
  4. [POKÉDATA // TERMINAL](https://pokemonkelompok10.streamlit.app/) (Full-Stack Web Dev & Project Manager, Streamlit ML)
  5. [Nusantara Atlas](https://nusantara-atlas.org/) (`Role: Data Contributor`, East Kalimantan focus)
- **Canvas Spotlight Portrait Reveal**: Background-free transparent portrait with 60fps 2D Canvas cursor spotlight (desktop) and tap toggle (mobile).
- **Achievement Spotlight**: [Beasiswa Kukar Idaman](https://bis.telkomuniversity.ac.id/beasiswa-kukar-idaman/)
- **Bilingual (`ID` / `EN`)** floating switcher defaulting to Bahasa Indonesia.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment & Security (Vercel)
Configured via `vercel.json` (`npm run build` -> `dist`) with strict HTTP security headers (`Content-Security-Policy`, `Strict-Transport-Security`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, and `Permissions-Policy`) and immutable static asset caching.
